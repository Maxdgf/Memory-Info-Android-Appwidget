# Memory-Info-Android-Appwidget
A simple widget built using **Jetpack Glance** that displays information about storage, RAM, and the device itself. The widget updates every **3 minutes** and occupies a **4x1 cell** area.

## Preview 🖼️
<img src="previews/preview.jpg" width=250>

## What does appwidget display? 🖥️
* 📱 Device data
    * Android version
    * SDK version
    * Model name
    * Manufacturer
* 💽 Storage memory data
    * Total memory in GB
    * Used memory in GB
    * Used memory percent %
* 🗃️ RAM data
    * Total memory in GB
    * Used memory in GB
    * Used memory percent %

## Android versions 🔃
Android 8 and later.

## Project installation ⌨️
1. Clone this repository `git clone https://github.com/Maxdgf/Memory-Info-Android-Appwidget.git`
2. Open project in **Android Studio**
3. Sync gradle files
4. Launch app on emulator or physical device
